# Food2Fuel
Food2Fuel (LoopFeed) — a web platform connecting restaurants, hotels &amp; banquet halls with biogas plants for organic waste pickup, delivery tracking, and invoicing.


Food2Fuel / LoopFeed is a web app that connects organic waste generators (restaurants, hotels, resorts, marriage halls, caterers) with biogas plants through a managed pickup-and-delivery pipeline.

A unified phone-number login automatically detects whether a number is registered — existing users go straight to their dashboard, new users are guided into role-based signup (Waste Generator / Biogas Plant / Delivery Partner) in the same screen.

Core flow: a generator requests a pickup → the system auto-assigns a biogas plant and a delivery partner → the delivery partner picks up the waste and shares live GPS location en route → drops it off at the plant → the plant weighs the batch and generates an invoice → the generator pays through the app → only then does the plant confirm handover, completing the batch and issuing a digital disposal/compliance record.

Key features:

Phone-based unified login/registration across 3 role-specific dashboards
Automated plant + delivery partner assignment (round-robin load balancing)
Real-time delivery partner location sharing (browser Geolocation), viewable by both generator and plant
Weight-based invoicing generated by the plant on arrival, with in-app payment and payment history
Digital compliance/disposal records for every completed batch
Fully client-side demo (vanilla HTML/CSS/JS, data persisted in localStorage) — no backend required to run
